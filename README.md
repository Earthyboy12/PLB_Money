# SlipTrack AI (ระบบวิเคราะห์สลิปธนาคาร & สรุปค่าใช้จ่าย)

แอปพลิเคชัน Mobile-First Web App สำหรับวิเคราะห์สลิปธนาคารไทยอัตโนมัติ คำนวณค่าใช้จ่ายย้อนหลัง และสรุปเป็นสถิติ/Dashboard สวยงาม

## ฟีเจอร์หลัก
1. **Mobile-First Design**: ออกแบบมาสำหรับการเปิดใช้งานผ่านเบราว์เซอร์บนโทรศัพท์มือถือ หรือกด "Add to Home Screen" เพื่อใช้งานเสมือนแอปจริง
2. **AI Vision Slip Analyzer**: รองรับการอ่านสลิปธนาคารไทยทุกสถาบัน (กสิกร K+, กรุงไทย Next, ttb touch, เป๋าตัง GLO, SCB ฯลฯ)
3. **Auto-Categorization**: จำแนกหมวดหมู่อัตโนมัติ (อาหาร, ชำระบิล/บัตรเครดิต, เติมเงิน, เสี่ยงโชค, ช้อปปิ้ง)
4. **Duplicate Detection**: ป้องกันการบันทึกสลิปซ้ำซ้อนด้วยหมายเลขอ้างอิง (Ref No.)
5. **Dashboard & Charts**:
   - กราฟโดนัทแสดงสัดส่วนค่าใช้จ่ายตามหมวดหมู่
   - กราฟแท่งแสดงยอดใช้จ่ายย้อนหลังตามวัน
   - สรุปยอดรวม, จำนวนรายการ, ยอดเฉลี่ยต่อสลิป, อันดับร้านค้าที่จ่ายบ่อย
6. **QR Code เชื่อมต่อมือถือทันที**: มี QR Code บนหน้าจอ สำหรับใช้กล้องมือถือสแกนเปิดใช้งานในวง Wi-Fi เดียวกันทันที

---

## วิธีเปิดใช้งาน

### 1. รันเซิร์ฟเวอร์
ดับเบิลคลิกไฟล์ `start.bat` หรือเปิด PowerShell แล้วรัน:
```powershell
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 2. เปิดใช้งาน
* **บนคอมพิวเตอร์:** เปิดเบราว์เซอร์ไปที่ `http://localhost:8000`
* **บนโทรศัพท์มือถือ (Wi-Fi เดียวกัน):** สแกน QR Code จากหน้าเว็บ หรือพิมพ์ URL:
  ```text
  http://192.168.1.221:8000
  ```

## การเชื่อมต่อ Google Gemini API (ฟรี)
ระบบรองรับทั้งโหมดทดสอบ และโหมด AI เต็มรูปแบบ:
1. เข้าไปที่ [Google AI Studio](https://aistudio.google.com/app/apikey) แล้วกด Create API Key
2. กดปุ่ม **"ตั้งค่า AI"** ที่มุมขวาบนของเว็บแอป
3. นำ API Key มาวางแล้วกดบันทึก
